# Proposal rendering rules
- Master geometry uses page-edge coordinates in mm; practice defaults are snapshots, proposal changes/reset are explicit, and cover furniture overrides only page one. Why: template editing must preserve existing documents and screen/PDF positions.
- Composer paging uses the existing PaginatedPreview/Paged.js from the canvas HTML at fixed A4 dimensions; zoom transforms sheets without reflow, and print/revision preparation exports those completed sheets only. Why: editing preview and exported pagination must be identical.
- Keep-with-next defaults are display defaults unless explicitly changed; page furniture is rendered in Paged.js margin boxes, and pagination observes edits with a 300 ms debounce independently of persistence. Why: existing documents and save timing must not be rewritten by presentation changes.
- Pagination waits for the proposal, blocks and every live quote snapshot to finish loading; superseded Paged.js runs release page listeners before detached staging is removed. Why: incomplete content must never be accepted as a printable page set or trigger late detached-page errors.
- Execute the non-polyfill Paged.js runtime inside a dedicated iframe realm, never import its Previewer into the app document; print reads completed sheets and styles from that frame. Why: Paged.js promotes print rules to screen CSS and must not hide application chrome.
- Split side panels overlay equal-width editor/page columns; persist drawer preferences by authenticated user ID in browser storage, and fit the editor through outer zoom without reflowing the A4 source. Why: panel state must not squeeze the document or change exported pagination.
- Block heading levels are display-only `content_rich.headingLevel` (missing = H1); section numbers and the index come from the shared pure numbering helper, and style-panel edits keep per-proposal local state until saves settle. Why: existing documents render unchanged and live sliders never snap back to an older save.
- Set default Paged.js page geometry as A4 as well as the content page name; keep the index atomic, generated list markers inside the column, and heading/actions in a fixed panel header with an independent scroll body and application deletion confirmation. Why: unnamed fragments and panel overflow must not hide furniture or controls.

- Typed proposal layouts are opt-in snapshots; Cover and Letter are excluded from content counters, and Letter drafting stays in authenticated server-only helpers. Why: preserve legacy proposals and isolate AI credentials.
- Guard unsupported CSS media preludes inside the iframe Paged.js runtime only. Why: its older CSS parser must not crash document pagination.
- Collapse print-hidden page-break markers onto the next printable block and pin explicit boundaries after Paged.js CSS parsing; never rewrite prose during pagination. Why: empty markers and aggregated CSS selectors must not swallow user-requested breaks.
- Document Gantts use a non-mutating WBS model and standalone named A4 landscape sheets with monthly columns, bounded rows and adapted master furniture; export retains mixed page sizes. Why: no rotated duplicates, clipped charts or browser shrink-to-fit.
